cargo build --release --manifest-path daemon/Cargo.toml --bin presence-daemon
node scripts/stage-daemon.mjs
presence daemon stop
presence daemon start

presence daemon start runs native/linux-x64/presence-daemon.
The stage script is what copies the release build there.
A cargo build that stays in daemon/target does not.

The four exports on that same start, when the shell does not already have them, are PRESENCE_PIPER_MODEL, PRESENCE_RHUBARB_BIN, WAYLAND_DISPLAY=wayland-1, and XDG_RUNTIME_DIR=/run/user/1000
